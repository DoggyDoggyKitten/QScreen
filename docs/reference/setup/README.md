# macOS layout references

Captured on macOS 27.0.1 on 2026-11-11, with the system interface in English.

- `wallpaper.png`: Wallpaper content area; the account sidebar is excluded.
- `screen-saver.png`: screen saver sheet with Custom and QScreen selected. No account name or personal photo is visible.
- `password.png`: Lock Screen content area showing Immediately; the account sidebar is excluded.

These images are design references only and are not bundled with the app. `App/SetupIllustration.swift` draws all onboarding diagrams on a shared 680 × 328 artboard. Window geometry, typography and mascot scale are shared across steps. The mascot moves next to its target so that its arm stays short. The interface labels follow the English macOS settings; the surrounding instructions support Chinese and English.

The app does not record the user's screen or request screen recording or accessibility access.
