QScreen

1. 将 QScreen.app 放到「应用程序」或用户的 Applications 文件夹，再打开。
2. 首次打开会进入设置向导，按五步完成安装、打开系统设置、选择 QScreen、立即要求密码和预览。
3. 向导使用统一比例的卡通设置示意图；中途退出会保留进度，也可在「设置 → 设置向导」重新打开。
4. 系统屏保选择需要你确认；立即要求密码由 App 检测。无需辅助功能或录屏授权。
5. 点击菜单栏图标或按 Control + Option + Q，选择状态并开始离席。

点击右侧分钟数可以调整返回时间。全屏预览不锁屏，按任意键或点击退出。

本包为临时签名的本地开发版本，尚未完成 Developer ID 签名和公证。
真实锁屏、MacBook 合盖与外接屏兼容性需在目标机器完成验收。
技术说明与验收步骤见 docs/DEVELOPMENT.md 和 docs/ACCEPTANCE.md。
